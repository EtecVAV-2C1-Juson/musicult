## Conteúdo

Neste repositório estão armazenadas os arquivos do projeto pedido, um site que se propõe a ensinar algo e então fazer um simulado para testar o conhecimento de quem está usando. O foco técnico é utilizar o banco de dados para armazenar as informações das questões para que as perguntas do simulado sejam sorteadas. Também visa aperfeiçoar técnicas de Mobile First e frisar o quão importante o design é para aplicações.

## Organização 

Os arquivos estão organizados em pastas, para facilitar a programação e a organização no geral.
